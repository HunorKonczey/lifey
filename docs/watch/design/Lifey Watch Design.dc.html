F5 — set logging from the watch (v2)
Placement rationale (F5/1): the log-set control gets a dedicated pager page (option b), first in the order log ↔ metrics ↔ controls. F4 already learned that bottom-anchored buttons clip on round bezels — that's why controls live on page 2 — so option (a) would reopen a solved problem. A dedicated page turns the whole safe area into one ~244 px tap target (5× the 48 px minimum, sweat-proof), with zero mis-tap risk near End/Pause, keeps the metrics page deliberately button-free, and extends the shipped pager naturally (page dots 2 → 3). Being page 1, a wrist-raise mid-set lands directly on it. Pending → confirmed is phone-acknowledged; the counter never shows an unconfirmed number.

F6 — standalone start from the watch (v2)
Watch owns the whole session locally: F5's log control runs in local mode (identical control, no pending state — instant confirm), rest timers are watch-local (1:30 default), and the finished session queues until the phone reconnects. Standalone is a normal mode, not an error — the indicator stays quiet. No ENDING phase; End goes straight to the summary.
